✅ 第一支影片製作清單
點擊項目打勾
  • 【音樂】 打開 suno.com → Custom Mode
  • 【音樂】 貼上太魯閣場景的 Suno Prompt，生成 3 個版本
  • 【音樂】 選最好的版本，用 Extend 延長到 3 分鐘
  • 【音樂】 下載音樂 MP3 檔
  • 【影片】 去 Pexels.com 搜尋「Taroko Gorge」下載 4K 影片
  • 【影片】 下載至少 3 個角度的場景影片（共 5~10 分鐘素材）
  • 【音效】 去 freesound.org 下載鳥叫聲 + 流水聲（CC0 授權）
  • 【剪輯】 開啟 DaVinci Resolve（免費）或 CapCut
  • 【剪輯】 導入影片 → 設定時間軸為 1 小時，影片片段循環播放
  • 【剪輯】 音樂軌道放底層，音效軌道疊加，調整音量比例 (音樂 70% : 音效 30%)
  • 【縮圖】 打開 Canva，使用 1280×720 尺寸
  • 【縮圖】 背景用 DALL-E 生成的太魯閣圖，加上標題文字
  • 【縮圖】 字體：粗體白字 + 黑色陰影，左下角放頻道 logo
  • 【上傳】 打開 YouTube Studio → 上傳影片
  • 【上傳】 貼上 SEO 模板（標題 + 描述 + 標籤）
  • 【上傳】 上傳自訂縮圖
  • 【上傳】 分類設定為「音樂」，語言設定為「中文（台灣）」
  • 【發布】 設定預約發布（建議週五晚上 8 點）
